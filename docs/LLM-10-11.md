# LLM 10.11 — Full-model next-token Training Loop

## Co jest gotowe

`FullModelTrainer` otrzymuje instancję `JarvisLanguageModel` i trenuje jej parametry **w miejscu**, więc późniejsze `model.predictNextToken()` używa wyuczonych wag.

Teacher forcing na znacznikach: `[BOS, a, b, EOS]`:

| Wejście | Poprawna odpowiedź |
|---|---|
| BOS | a |
| a | b |
| b | EOS |

Strata uśredniona po `T` targetach:

`L = (1/T) * Σ CrossEntropy(logits[t], targets[t])`

Przy propagacji gradientu przez wszystkie warstwy LM Head, `LayerNorm`, bloki (od końca), embedding pozycji i tokenów uwzględniamy tę samą skalę `1/T`. Gradienty parametrów współdzielonych sumujemy po pozycjach.

`clipScale = min(1, maxGradientNorm / globalGradientNorm)` — mnożnik stosowany przed AdamW. Weight decay jest stosowany do macierzy wag, a nie do biasów i `LayerNorm` affine. PAD embedding ID 0 nie jest trenowany.
